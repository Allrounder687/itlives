# Plan the Work

1. **The moment you have an idea, make a CE plan.md**
   Start every real task by having CE write the plan first.

2. **Don't read the plan.md**
   Skim the title, ask for a TLDR, then let the agent work.

3. **Use /ce-plan for your deepest non-engineering work**
   First ask how the agent will use your context.

4. **Research before you plan: last30days**
   Check current tools, docs, and community learnings first.

5. **Granola all the things, and put the raw transcript in your LLM**
   Paste the full transcript and let the agent extract signal.

6. **Your notes are your agent's knowledge base**
   Give agents access to notes, plans, and decisions.

7. **Proof: for sending a plan to a colleague**
   Turn plan.md into a doc collaborators can comment on.
